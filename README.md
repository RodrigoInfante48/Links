# Links — Rodrigo Infante

Landing de enlaces propia, sin dependencias ni proceso de compilación, lista para GitHub Pages.

- `index.html`: estructura (hero, carrusel, redes y botón de contacto)
- `styles.css`: estilos y animaciones
- `script.js`: carrusel 3D. **Edita el arreglo `PRODUCTS` al inicio** para cambiar nombres, textos, colores o enlaces.

## Publicar en GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
